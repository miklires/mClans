# Changelog

## 1.1.0 - 2026-08-28

- Added confirmed ownership transfer and offline member management.
- Added mutual alliances, enemy/neutral relations and allied friendly-fire protection.
- Added clan homes with cooldowns and asynchronous teleportation.
- Added Vault-backed deposits, officer withdrawals and compensating ledger entries.
- Added `/clan top` and expanded the command suggestions.
- Hardened naming regex, progression validation, arithmetic limits and invite expiry.
- Added transactional tests for ownership, diplomacy, homes and leaderboards.
- English remains the default; set `language: ru_RU` for Russian.

## 1.0.0

- Added persistent clan lifecycle, roles, invitations and member limits.
- Added configurable levels, PvP points and same-victim anti-farm protection.
- Added friendly fire, clan chat, information GUI and bank ledger storage.
- Added asynchronous H2 storage and Bukkit Services API.
